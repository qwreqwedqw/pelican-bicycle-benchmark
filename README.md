## 🎯 评测背景与严格测试条件

「让一只鹈鹕骑自行车并动起来」是考验大模型空间推理、非人类生物解剖学认知、机械连杆物理学以及纯前端代码还原度的经典难题。

为了保证对比的严谨与纯粹性，本次测试严格遵循以下条件：
- **仅对比两大顶级模型**：Google Gemini 4 Argon 与 Anthropic Claude Opus 5.5。
- **排除智能体（Agent）辅助**：完全不借助 Agent 框架（无外部调试工具、无多步自动循环修正），纯依靠单轮 Prompt 一次性吐出完整的交互 HTML/SVG 代码。
- **思考强度拉到极高**：

| 模型 | 测试平台 / 渠道 | 思考强度设定 | 生成模式 |
| :--- | :--- | :--- | :--- |
| **🔷 Google Gemini 4 Argon** | **Google AI Studio** | **思考强度拉到最高 (Max Thinking Budget)** | 单轮纯对话 (非 Agent) |
| **🟧 Anthropic Claude Opus 5.5** | **对话平台 (Chat)** | **思考强度极高 (High Thinking)** | 单轮纯对话 (非 Agent) |

## 🚀 开启 GitHub Pages 在线免下载预览方法

1. 打开 GitHub 仓库页面：[qwreqwedqw/pelican-bicycle-benchmark](https://github.com/qwreqwedqw/pelican-bicycle-benchmark)
2. 点击上方的 **Settings**（设置） $\rightarrow$ 左侧导航的 **Pages**。
3. 在 **Build and deployment** 下方的 **Branch** 选择：
   - 分支选择：`main`
   - 目录选择：`/ (root)`
4. 点击 **Save**（保存）。
5. 等待 1 分钟左右刷新页面，顶部即会显示可直接公开分享的在线演示网址！
